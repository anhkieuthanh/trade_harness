# Plan: Build Svelte UI Execution Flow Visualizer for TradeHarness

This plan proposes the creation of a modern, premium web UI built using the **Svelte** framework (via Vite) and a supporting Python API backend. The UI will visualize the detailed execution steps, checks, and interventions of the TradeHarness agent runtime (episodes, steps, risk gates, trajectory monitoring, and market snapshot data).

## Proposed Changes

### Backend Component
We will create a lightweight Python HTTP server to parse the trajectory logs and control settings, and expose them as JSON endpoints.

---

#### [NEW] [ui_server.py](file:///Users/atif/Public/TradeHarness/tradeharness/ui_server.py)
A built-in Python API server that:
- Reads `var/trajectories/episodes.jsonl` and exposes:
  - `GET /api/episodes` - lists recent episodes.
  - `GET /api/episodes/<id>` - details of a specific episode.
- Reads and updates `var/control/state.json`:
  - `GET /api/control` - get strategy/risk settings.
  - `POST /api/control` - update settings.
- Runs offline evolution.
- Serves the built Svelte static files from `ui/dist`.
