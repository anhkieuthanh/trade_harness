# TradeHarness

## What This Is

TradeHarness is an algorithmic trading harness and agent architecture for backtesting and execution.

## Core Value

Enable high-fidelity visualization and regulatory oversight of agent trading runs.

## Requirements

### Active

- [ ] **VIS-01**: Svelte dashboard with light-white theme visualizer for TradeHarness.
- [ ] **VIS-02**: Sidebar listing recent episodes with query search/filtering.
- [ ] **VIS-03**: Interactive node execution flow showing step-by-step observation, decisions, and safety/risk layers gates.
- [ ] **VIS-04**: Custom inline SVG candlestick and volume chart for market snapshot visualization.
- [ ] **VIS-05**: Settings panel editing strategy modes and risk guard parameters.
- [ ] **VIS-06**: Offline evolutionary evolution batch run control and status tracking.
- [ ] **VIS-07**: Backend Python API server integrated with supervisor.py serving static assets and API endpoints.
